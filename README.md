An offline web app that turns a photo and a caption into GTA 6-style multi-panel cover art. Pick a panel layout, assign photos per panel, set focal points and colour grades, add the masthead title, tagline, age badge and barcode — then export the finished cover as a PNG. Everything runs client-side; no network, no libraries.

Built for the [gta6-cover-art-01 bounty on make.fun](https://make.fun/bounty/gta6-cover-art-01).

## Run it

```
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Two sample photos are included so the studio opens on a finished cover.
